# VILA Waitlist

A community-first early-access website for VILA, built with React (Create React App) + TypeScript and Node.js + Express + TypeScript + MongoDB.

## Separate client and server projects

There is **no root package.json or npm workspace**. Run `npm install` separately inside `client/` and `server/`. Each project has its own `node_modules/` and `package-lock.json`, which npm creates when dependencies are installed.

```text
vila-waitlist/
├── client/
│   ├── package.json
│   ├── package-lock.json    # generated by npm install
│   ├── node_modules/       # local dependencies, gitignored
│   ├── public/
│   └── src/
├── server/
│   ├── package.json
│   ├── package-lock.json    # generated by npm install
│   ├── node_modules/       # local dependencies, gitignored
│   ├── .env                # local secrets, gitignored
│   └── src/
└── README.md
```

## Run the backend

Open terminal 1:

```bash
cd server
npm install
cp .env.example .env
# Edit .env with a MongoDB URI, ADMIN_PASSWORD (12+ characters),
# and JWT_SECRET (32+ characters).
npm run dev
```

`npm run dev` uses **nodemon + tsx**. API: http://localhost:4000.

Make sure MongoDB is running locally or set `MONGODB_URI` to your MongoDB Atlas connection string.

## Run the frontend

Open terminal 2:

```bash
cd client
npm install
npm start
```

Client: http://localhost:3000. The Create React App development proxy routes `/api` requests to http://localhost:4000.

Both commands assume your terminal begins in the repository root. When you're already in `server` or `client`, omit that `cd` command.

## Community onboarding

1. A VILA admin contacts a community or group.
2. Admin visits `/create`, signs in, and selects **Create community** or **Create group**.
3. Admin copies or shares the dedicated invite link (including WhatsApp sharing).
4. Members sign up through `/c/:slug` or `/g/:slug`. The signup source is saved.
5. People without an affiliation register freely at `/join`.

Routes:
- `/` — marketing homepage
- `/join` — independent registration
- `/create` and `/admin` — admin-only creation and link management
- `/c/abuloma` — example community invitation (must be created first)
- `/g/abuloma-youth` — example group invitation (must be created first)

## Production notes

This is an MVP, not a production-hardened registration system. Before a public launch: configure email verification, privacy notice, better bot protection, HTTPS, logging, and appropriate data retention policies. Opening an invitation link does not prove residency or group membership.
